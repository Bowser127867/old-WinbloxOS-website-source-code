# WinbloxOS — original-style version

Reconstructed from the original-style project before the countdown and music additions.
The homepage includes fanart and the website code. Double Trouble remains excluded.
Existing routes and external links are preserved. The safe Flask startup guard remains.

Install requirements.txt in a Python 3.9+ virtualenv. For local use run python main.py.
On PythonAnywhere, keep the project directory on sys.path and import:

    from main import app as application

This archive has not been deployed. It is not a byte-for-byte historical backup.
